# Contributing

Thanks for helping improve svelte-tunnel.

## Setup

```sh
pnpm install
pnpm dev
```

## Guidelines

- Keep library changes in `src/lib`.
- Add or update tests for behavior changes.
- Run checks before opening a PR:

```sh
pnpm check
pnpm test
pnpm lint
```

## Pull requests

1. Fork and create a branch.
2. Make a focused change.
3. Open a PR with a short description of the problem and the fix.

## Questions

Open an issue on [GitHub](https://github.com/bridge-kit/svelte-tunnel/issues).
